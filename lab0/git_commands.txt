git clone - создание копии удалённого репозитория на локальном компьютере

git status - отображение состояния файлов в рабочей директории (изменённые, добавленные, неотслеживаемые)

git add <file> - добавление файла в область подготовленных изменений (staging area) для следующего коммита

git commit -m "message" - создание коммита (снапшота) со всеми подготовленными изменениями

git push - отправка локальных коммитов в удалённый репозиторий

git init - инициализация нового репозитория в текущей папке

git pull - получение и слияние изменений из удалённого репозитория

git branch - просмотр списка всех веток в репозитории

git log - просмотр истории коммитов с их хешами, авторами и датами

git diff - отображение различий между текущими изменениями и последним коммитом
